# EstateHawk SEO baseline and work plan — 2026-11-09

## Scope and evidence

- Production: `https://getestatehawk.com`, 19 URLs in the live sitemap, checked on 2026-11-09.
- Ahrefs Site Explorer and Keywords Explorer opened in the user's browser. Ahrefs numbers are third-party estimates, not Google Search Console measurements.
- Public HTML, sitemap, robots, internal links, schema, page headings, image markup, and asset sizes were checked. Logged-in pages and private lead data are outside the public SEO surface.
- Google's current [Search Essentials](https://developers.google.com/search/docs/essentials/technical), [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), and [sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) were consulted.

## Verified baseline

- All 19 sitemap URLs returned HTTP 200, one H1, a title, a description and a matching canonical URL. No `noindex` was found on those 19 pages.
- A crawl of internal links from those URLs found 25 distinct same-site targets and no broken targets or sitemap orphans.
- `/robots.txt` allows the public site, points to `/sitemap.xml`, and disallows `/app`, `/api/` and `/login`. The empty `/blog` is deliberately noindex and absent from the sitemap until an article is published.
- Public pages render their main text in the server's HTML response. JSON-LD is present on key pages. Empty `alt` attributes on most inspected images are intentional decorative images beside visible text; do not bulk-fill them with keyword-stuffed descriptions.
- Homepage HTML is about 63 KB uncompressed. Its largest sampled image is about 39 KB; sampled fonts are about 37 KB and 48 KB. Field Core Web Vitals were **not** measured, so no performance score is claimed.
- Ahrefs reported DR 0, 0 organic keywords, estimated organic traffic 0, and 55 referring domains, all nofollow, for `getestatehawk.com` on 2026-11-09. This is an early/limited external index view, not proof of zero Google traffic or poor indexing.

## Keyword research (Ahrefs, US, monthly estimates)

- `tax delinquent property list`: search volume 200, keyword difficulty 16. Relevant to existing `/counties` and state coverage pages.
- `tax delinquent property leads`: search volume 20, difficulty not available. Relevant to the homepage and `/features`.
- `motivated seller leads`: search volume 400, difficulty 4, CPC about $7. This broader term does **not** justify claiming county tax delinquency proves sale intent. Use it only for a balanced educational comparison, not a misleading product promise.

## Issues and priorities

1. **Measurement:** The `https://getestatehawk.com/` URL-prefix property was added and ownership verified in Google Search Console on 2026-11-09. `/sitemap.xml` was submitted and processed successfully with 19 **discovered**, not necessarily indexed, pages. URL Inspection says the homepage is on Google. `/counties/texas` was "Discovered - currently not indexed"; Google's live test found it available and indexable, and an indexing request was acknowledged. Performance, aggregate indexing and Core Web Vitals reports were still processing immediately after setup; return after Google populates them. Ahrefs cannot replace Search Console. Also inspect first-party traffic funnel and privacy-safe analytics for organic conversions.
2. **Sitemap freshness:** The earlier production sitemap generated today's `<lastmod>` for every page whether changed or not, plus `changefreq` and `priority` values that Google ignores. Released code omits invented static dates and uses actual CMS update dates for published blog posts. The live sitemap was checked after deployment and had no invented `<lastmod>` values.
3. **Content accuracy:** Homepage and several marketing sections described tax-delinquent owners as confirmed motivated sellers, implied every property maps, and implied every nightly sync succeeds. Code now corrects the homepage, score description, map description, FAQ, and how-it-works copy. Remaining guides and About copy need editorial review for the same issue before expanding content.
4. **Content depth and topical authority:** Only three short guides and no published blog posts exist. Build a small, source-backed cluster around county delinquent lists, how to verify an owner, taxes vs tax liens vs tax sales, county data limitations, offer due diligence, and state-specific processes. Add primary county/statute citations, review dates and a named, qualified reviewer where appropriate. Publish accurate articles through the existing CMS, then link them from relevant coverage pages. Do not create hundreds of thin county pages.
5. **Off-page authority:** Ahrefs sees no followed referring domains. Seek genuine mentions from relevant investor publications, local real estate associations, tool roundups and partners. Do not buy bulk links or treat the 55 nofollow references as equivalent to editorial endorsements.
6. **Technical follow-up:** Verify actual Core Web Vitals on mobile using PageSpeed Insights/Search Console field data; inspect indexing in Search Console; validate representative JSON-LD with Google's Rich Results Test. `/llms.txt` currently returns 404, but it is optional and not a Google indexing requirement.
