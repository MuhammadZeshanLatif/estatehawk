EstateHawk Helper (Chrome extension)

What it does: when you click "Click to see contact info" on a deal page, it opens that owner's Google search
in a minimized Chrome window, reads only the AI Overview text, closes the window, and sends the text to the
dashboard, which keeps the phone numbers and emails. It runs only when you click. It never runs on its own.

Install once:
1. Open chrome://extensions in Chrome.
2. Turn on "Developer mode" (top right).
3. Click "Load unpacked" and pick this folder: E:\Projects\EstateHawk\estatehawk\extension
4. Reload the EstateHawk tab (F5).
